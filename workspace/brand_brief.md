# NewEra AI Agent — brand intelligence

**Source inspected:** https://newera.namansoni.in (HTTP 200, 2026-10-14); page title, rendered text, metadata, schema.org `WebApplication`, FAQ, and how-to content extracted from the live homepage HTML. Public URL and founder credit were directly present on the site.

## Brand proposition
NewEra is a free, browser-based autonomous coding agent by Naman Soni. The key promise is not “chat with code” but a complete delivery loop: describe an app in plain English → agent plans and writes project files in an inspectable virtual workspace → push to GitHub only after user consent → real GitHub Actions CI build → read failure logs and fix → deploy to Cloudflare Pages, with EdgeOne as fallback → share a live URL. The site repeatedly contrasts a shipped, built application with a code snippet or demo sandbox.

## Accurate capability details from the site
- Multi-agent planning and coding; larger work can use up to four parallel coder agents.
- Real Linux VM execution for larger full-stack builds; smaller/static work may be authored locally and still verified by CI.
- Live web research, page extraction, and up-to-date library documentation.
- Browser-hosted Python, SQL, FFmpeg, and Git runtimes.
- Portable `.newera` project export/import.
- No login, no credit card, and no setup; model keys are managed server-side.
- Repositories are consent-gated (public or self-clean); self-clean repos are deleted when the task ends.
- Cloudflare Pages primary deployment, EdgeOne fallback.
